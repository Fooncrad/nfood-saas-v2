# Auth mobile visual check

تمت معاينة `/register` و`/login` على viewport بحجم 390x844 بعد توحيد الغلاف.

تظهر شاشة التسجيل الآن ببطاقة زجاجية مضغوطة، عنوان واحد دون تكرار، زر رجوع واضح، مؤشر خطوات، وبطاقتي نوع الحساب ضمن الشاشة دون قص. تظهر شاشة الدخول بنفس النمط العام مع عنوان واضح، أدوار سريعة، حقول البريد وكلمة المرور، زر إظهار كلمة المرور، ورسالة تحقق وزر دخول كامل العرض. بقيت عناصر Google واستعادة كلمة المرور أسفل الشاشة ضمن التمرير الداخلي الطبيعي، ولم يظهر قص للحقول أو كسر لاتجاه الواجهة.
