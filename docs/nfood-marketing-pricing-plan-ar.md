# خطة التسويق الرقمي وهيكلة الباقات — NFOOD 2026

## 1. خطة التسويق الرقمي التدريجية
تهدف الخطة إلى بناء الثقة أولاً ثم التوسع عبر محتوى المستخدمين.

### المرحلة الأولى: بناء الثقة والأساس (0–30 يوم)
- **المحتوى التعليمي:** سلسلة فيديوهات قصيرة توضح كيفية إعداد المنيو متعدد اللغات واستخدام KDS.
- **تجارب رائدة:** توثيق قصة نجاح 3 مطاعم مختارة (مثل ناصر كافيه) وإبراز الكفاءة التشغيلية.
- **التواصل المباشر:** حملات بريدية موجهة لأصحاب المطاعم في الرياض وجدة مع عرض "تأسيس مجاني".

### المرحلة الثانية: التبني والانتشار (31–60 يوم)
- **نظام الإحالات:** تفعيل مكافآت مجزية للعملاء الذين يرشحون مطاعم جديدة، والمطاعم التي تدعو شركاء.
- **Webinars تشغيلية:** ندوات عبر الإنترنت حول "تحويل صور الأكل إلى مبيعات" بالتعاون مع صنّاع محتوى.
- **التواجد المحلي:** تحسين SEO للمطاعم المشاركة لظهورها في "أفضل مطاعم [المنطقة]" عبر بوابة NFOOD.

### المرحلة الثالثة: النمو المتسارع (61–90 يوم)
- **مواسم NFOOD:** إطلاق حملات مرتبطة بمواسم الطعام (رمضان، الصيف، اليوم الوطني) تبرز ميزات الحجز المسبق.
- **إعلانات إعادة الاستهداف:** استهداف العملاء الذين تصفحوا مطاعم معينة ولم يطلبوا، بعروض مخصصة بموافقة المستخدم.
- **تفعيل Studio:** مسابقات لصناع المحتوى لأفضل صور أطباق، لزيادة مخزون Trend Kitchen.

### المرحلة الرابعة: التوسع والتميز (بعد 90 يوم)
- **سوق المحتوى العالمي:** فتح Trend Kitchen للمطاعم خارج المنصة كقناة إيراد مستقلة.
- **White Label:** تقديم نسخ مخصصة للمجموعات الغذائية الكبرى مع حوكمة كاملة.

## 2. هيكلة الباقات الثلاث (Value-Based Pricing)

### فئة المطاعم (التشغيل والنمو)
1. **باقة Basic (التأسيس):** تشمل المنيو الرقمي، POS أساسي، وطلبات الطاولات. (مثالية للمطاعم الناشئة).
2. **باقة Pro (التسويق):** تشمل باقة Basic + نظام الولاء، حجز الطاولات، وإدارة المخزون. (الأكثر طلباً).
3. **باقة Business (التوسع):** تشمل باقة Pro + إدارة فروع متعددة، تحليلات متقدمة، وتكاملات API.

### فئة العملاء (التجربة والمحتوى)
1. **باقة Free (الاكتشاف):** طلب وحجز مجاني، ومحفظة مكافآت أساسية.
2. **باقة Plus (التميز):** مكافآت مضاعفة، Profile مخصص، ومساحة Studio سعة 5GB.
3. **باقة Pro (الاحتراف):** بيع محتوى غير محدود، ميزات حصرية، ومساحة Studio سعة 20GB.

### فئة الإدارة (الحوكمة والتحكم)
1. **باقة Starter:** إدارة حتى 10 مطاعم، تقارير أساسية، ودعم فني قياسي.
2. **باقة Growth:** إدارة حتى 50 مطعماً، حملات تسويقية، وتحليلات أداء المنصة.
3. **باقة Enterprise:** مطاعم غير محدودة، حوكمة متقدمة، وفصل مالي مخصص.

## 3. مؤشرات الأداء الرئيسية (KPIs)
- **تفعيل المطعم:** الوقت من التسجيل حتى أول طلب ناجح.
- **معدل العودة (Retention):** نسبة العملاء الذين يطلبون أكثر من مرتين شهرياً.
- **تكلفة الاكتساب (CAC):** تكلفة جذب مطعم جديد مقابل الإيراد المتوقع.
- **حجم التداول (GMV):** إجمالي قيمة الطلبات ومشتريات المحتوى عبر المنصة.
