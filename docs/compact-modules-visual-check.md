# معاينة الوحدات الداخلية المدمجة

- معاينة سطح المكتب: شبكة النظرة العامة متوازنة، الشريط الجانبي ظاهر بعرض موسّع، والبطاقات المدمجة لا تتداخل.
- معاينة الجوال: البطاقات تتحول إلى عمودين، زر القائمة ظاهر، والنصوص الأساسية ضمن العرض دون قص جوهري.
- تحقق وظيفي: صفحة الطلبات تستخدم CompactOrdersBoard، وحساب السائق يستخدم CompactModuleSummary مع إجراءات الحالة الحالية.
- ملاحظة: المعاينات التقطت صفحة النظرة العامة الحالية؛ التحقق البنيوي يغطي تركيب وحدتي الطلبات والسائقين مباشرة.
