# NFOOD Expansion Roadmap Gap Analysis

## نطاق المراجعة

تمت مقارنة المتطلبات الواردة في `Pasted_content.txt` مع بنية المشروع الحالية، مع اعتبار الميزات التي تعتمد على مزود خارجي أو مفتاح إنتاجي غير مفعلة حتى تُضاف أسرارها من لوحة الإعدادات. هذه المراجعة لا تعتبر الميزات المؤجلة مكتملة، بل تحولها إلى أولويات تنفيذ واضحة.

| المجال | الحالة الحالية | الفجوة أو الخطوة التالية |
|---|---|---|
| الدخول الموحد والأدوار | منفذ بأدوار تشغيلية وتوجيه وصلاحيات واختبارات | استكمال صفحات التسجيل المستقلة وEmail Verification وOTP الإنتاجي عند إضافة مفاتيح المزود |
| صفحات التسويق العامة | أضيفت `/pricing` و`/features` و`/how-it-works` وLanding للزائر | إضافة إدارة المحتوى من لوحة الإدارة وFAQ ولقطات حقيقية بدل البيانات العامة |
| Super Admin | إدارة المطاعم والميزات والاشتراكات والصحة والسجلات موجودة | توسيع صفحات Payments وInvoices وSupport وLanguages وCurrencies كإدارات مستقلة عند الحاجة |
| المطعم والفروع | لوحة مطعم، منيو، فروع، POS، KDS، مخزون، فريق، توصيل ومهام موجودة | استكمال صلاحيات عضوية الفرع والتقارير المتقدمة حسب الباقة |
| العميل والضيف | Guest Checkout وCustomer Portal وVCard وبعض الولاء موجودة | استكمال تحويل الضيف إلى عميل، Abandoned Cart، وتخصيص الملف العام |
| التوصيل والسائق | دورة السائق والوثائق وETA وحالات فشل التوصيل موجودة | إضافة التتبع الحي وإشعارات البريد/Push وربط الخرائط الإنتاجي |
| PWA وOffline | Manifest وService Worker وOffline POS وInstall Prompt موجودة | فصل تطبيقات PWA حسب الدور وتحسين مزامنة التعارضات |
| المنيو العامة | لغات AR/EN/FR/UR، QR، بحث، تصفية، سلة، حجز وتبديل لغة موجودة | إضافة SEO وQR Analytics وثيمات مدارة من لوحة المطعم |
| الباقات والحدود | Feature Access وPlans وOverrides وAdd-ons موجودة | ربط الدفع الفعلي والترقية والتجديد عند تفعيل بوابة الدفع |
| التكاملات | واجهات إعدادات وتوثيق وربط أساسي موجود | إدخال مفاتيح مزودي الدفع والرسائل وWhatsApp من لوحة الإعدادات |
| الجودة وتجربة الاستخدام | حالات Loading/Empty/Error واختبارات مرحلية وتصميم RTL موجودة | توسيع اختبارات E2E وإتاحة الوصول والوضع الداكن على الوحدات المتبقية |

## ترتيب التنفيذ المستمر

الأولوية الأولى هي تثبيت التسجيل المستقل والتحقق من البريد والهاتف بوضع آمن قابل لتبديل المزود. بعدها يأتي مركز إدارة الباقات والحدود مع تجربة الترقية، ثم تحسين المنيو العامة وSEO والتحليلات، ثم التتبع الحي والتكاملات الخارجية. كل تكامل يحتاج مفتاحًا سيبقى خلف إعداد واضح وموسوم بأنه غير مفعّل حتى تُضاف قيمته الحقيقية.
