# فحص بصري لتجربة حساب العميل

على شاشة 390x844 ظهرت صفحة `/customer-register` كبطاقة مستقلة ومختصرة، مع حقول الاسم والبريد وكلمة المرور والتأكيد وزر واضح، ومن دون عناصر تسجيل المطاعم. كما ظهرت بوابة `/customer-portal` بتقسيم مباشر للطلبات والحجوزات والمكافآت وStudio وطلبات المحتوى والملف وتبديل الحساب، مع بطاقات ملونة قابلة للمس. ما يزال مركز الإشعارات والمحفظة أسفل الجزء المرئي في هذه اللقطة، لكنه محمّل ضمن الصفحة؛ لا يوجد قص أفقي أو نافذة تغطي المنيو.
