## تفسير التغذية التفاعلية

التغذية التفاعلية في الوحدات المثبتة ليست ادعاءً بأن كل عملية تستخدم Toast موحدًا؛ بعض التدفقات تستخدم بطاقة نجاح أو نص خطأ موضعيًا بدل toast لتظل الرسالة مرتبطة بالسياق. تم منع أزرار الإجراءات الوهمية، وتُظهر المصفوفة نوع feedback المتوقع بدل إخفاء غيابه.

## حدود النطاق

هذه مصفوفة توثيقية مرتبطة بفحص المصدر وملفات الاختبار الحالية، وليست اختبار متصفح E2E لكل خلية. الميزات غير الموجودة في الجدول، مثل Driver Workflow وKitchen Printers وSSO، لا تُعد مغطاة بهذه المصفوفة.
