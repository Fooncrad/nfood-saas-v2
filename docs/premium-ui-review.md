# مراجعة الهوية البصرية الفاخرة

تمت مراجعة لوحة NFOOD على سطح المكتب 1280px والهاتف 390px باتجاه RTL. ظهرت الخلفية اللؤلؤية المتدرجة، الحواف الدائرية، ظلال البطاقات، وتباين البرتقالي التوقيعي بصورة متسقة. على الهاتف تكدست البطاقات رأسيًا دون شريط تمرير أفقي، وبقي زر القائمة والرأس قابلين للوصول. تظهر مؤشرات «جارٍ» فقط أثناء دورة الاستعلام الأولية، ولا توجد أرقام تشغيلية وهمية.

أضيف خط Cairo في قالب العميل، ونظام زجاجي وحركة دخول محسوبة مع احترام `prefers-reduced-motion`. لم تُغيّر التعديلات عقود tRPC أو صلاحيات الأدوار.
