# مراجعة البنود المفتوحة وربط الأدوار

## النطاق

راجعت البنود المفتوحة في `todo.md` وربطتها بالأدوار الحالية: **Super Admin**، مدير المطعم، السائق، العميل، الكاشير، النادل، والمطبخ. الوحدات التشغيلية الحالية تستخدم حراس الدور و`restaurantId`/`branchId` قبل القراءة أو الكتابة، وتغطي اختبارات `platform.router` و`role-permissions` و`auth.testlogin` العزل والوصول الأساسي.

## البنود التي تحتاج مزودًا خارجيًا

| البند | الدور أو النطاق | الحالة الآمنة الحالية | شرط التفعيل |
|---|---|---|---|
| Google OAuth | جميع الأدوار حسب سياسة الدخول | غير مفعّل، ولا يغيّر مسار الدخول التجريبي | مفاتيح Google وredirect URI |
| OTP | جميع الأدوار التي يسمح بها الأدمن | غير مفعّل | مزود SMS ومفتاح API وسياسة معدلات الإرسال |
| Passkey | جميع الأدوار | غير مفعّل | WebAuthn RP ID وorigin وإدارة الأجهزة |
| Birthday/Re-engagement | مدير المطعم وSuper Admin | معاينة الجمهور وقواعد الجدولة موجودة، الإرسال متوقف | مزود رسائل، قالب، ومهمة Heartbeat منشورة |
| بريد قبول السائق | Super Admin/مدير المطعم والسائق | حالة الطلب محفوظة دون إرسال خارجي | SMTP أو مزود بريد ومفتاح إنتاجي |
| التتبع الحي للسائق | السائق والمطعم والعميل | دورة الحالات وETA محفوظة، لا يوجد بث حي خارجي | مزود realtime وتتبع وموافقة خصوصية |

## نتيجة المراجعة

لا يُظهر أي دور وحدة خارج نطاقه بسبب هذه البنود؛ كما لا تُستخدم بيانات وهمية أو مفاتيح مضمّنة لتقديم التكاملات على أنها مفعّلة. أُغلقت المراجعة الحالية بعد نجاح suite المشروع، بينما تبقى البنود أعلاه مفتوحة حتى توفير متطلبات المزودات.
