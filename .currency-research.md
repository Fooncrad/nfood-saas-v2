# Currency research

- Source: https://www.iso.org/iso-4217-currency-codes.html
- ISO states ISO 4217 provides internationally recognized alphabetic and numeric currency codes and includes currencies from Afghanis to Zambian Kwacha.
- Implementation decision: use three-letter ISO codes in restaurant settings and derive decimal precision from the catalog. Preserve SAR as a legacy option for existing restaurants while adding African currency codes.
- Source checked: https://www.iban.com/currency-codes
- Used as a secondary cross-check for African country/currency code coverage; the project stores the ISO alphabetic code, not a scraped website label.
