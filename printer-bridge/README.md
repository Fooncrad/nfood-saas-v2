# بوابة طباعة NFOOD

تشغّل هذه البوابة على جهاز الكاشير داخل شبكة المطعم. وضع المتصفح لا يحتاجها، بينما فحص طابعات الشبكة والطباعة المباشرة عبر IP/Port يحتاجانها. USB وBluetooth يحتاجان محولًا محليًا يقدّم نفس عقد `/probe` و`/print`.

شغّلها عبر:

```bash
PRINTER_BRIDGE_TOKEN='ضع-رمزًا-طويلًا' PRINTER_BRIDGE_PORT=8765 node index.mjs
```

المسارات المدعومة حاليًا هي `GET /health`، و`POST /probe` لجسّ منفذ TCP، و`POST /print` لإرسال payload نصي إلى طابعات ESC/POS الشبكية. لا تُعرّض المنفذ للإنترنت مباشرة؛ استخدم شبكة محلية أو نفقًا موثوقًا مع HTTPS ورمز وصول.
